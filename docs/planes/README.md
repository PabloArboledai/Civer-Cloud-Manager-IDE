# Planes de trabajo compartidos

Resumen: esta carpeta centraliza planes accionables para que humanos y agentes trabajen en paralelo sin perder contexto ni duplicar decisiones.

## Planes activos

- `docs/planes/openai-provider-oficial/README.md`
  Roadmap oficial para soporte OpenAI/Codex sin depender de captura de sesiones de navegador.

## Regla de uso

- Usa estos planes como fuente de verdad operativa antes de empezar a editar código.
- Si un agente toma una fase o subtarea, debe actualizar el plan correspondiente o crear artefactos OpenSpec asociados.
- No se deben almacenar tokens reales, callbacks completos ni secretos en esta carpeta.
